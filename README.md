# ShuleDirect Pro — The Sovereign Institutional Hub

## 🏛️ Project Vision
ShuleDirect Pro is a **High-Fidelity Institutional Ecosystem** designed specifically for the modern Tanzanian educational landscape. It transitions schools from fragmented, manual processes to a unified **Sovereign Node** architecture, ensuring data integrity, financial assurance, and academic distinction for the 2026 season and beyond.

## 🚀 The Problems We Solve
* **Data Fragmentation**: Replaces disconnected Excel sheets and paper registers with a **Single Source of Truth** in the cloud.
* **NECTA Alignment**: Automates the "Grading Hustle" by providing real-time point aggregation and division classification (I-IV, 0) aligned with national standards (PSLE, FTNA, CSEE).
* **Communication Gaps**: Bridges the parent-teacher divide through **Omnichannel Synchronization** (WhatsApp/SMS) via n8n and Evolution API.
* **Revenue Assurance**: Integrates with financial gateways to manage Control Numbers and eliminate revenue leakage.

## ⚙️ Technology Stack (The "Engine")
* **Framework**: Next.js 15 (App Router) — Optimized for speed and "Pure Performance" SEO.
* **Database**: Firebase Firestore — Real-time synchronization across all administrative device nodes.
* **AI Engine**: Genkit + Gemini 2.5 Flash — Powers "Smart Enroll" (Vision AI) and narrative student progress summaries.
* **Orchestration**: n8n — The automation brain for dispatching WhatsApp reports and attendance alerts.
* **Aesthetics**: Tailwind CSS + ShadCN UI — High-density, professional ERP design.

## 🎨 Design Philosophy: "The Audit Node"
The system utilizes an ultra-rigid, professional aesthetic designed to feel like an authoritative government ledger.
* **Primary (#1F5BA6)**: Sovereign Blue for trust and stability.
* **Accent (#945CE6)**: AI Purple for futuristic intelligence nodes.
* **Typography**: Space Grotesk (Headlines) and Inter (Body) for technical clarity.
* **UI Pattern**: Glassmorphism and horizontal scroll-snap for an elite mobile auditing experience.

## 🤖 Core Modules
1. **Student Hub**: Unified registry with AI-powered form scanning and photo identity nodes.
2. **Attendance Ledger**: Real-time daily registers with automated parental notification dispatches.
3. **Financial Hub**: Control number generation, ClickPesa reconciliation, and operational petty cash management.
4. **Logistics Node**: Real-time dormitory occupancy (Hostel Hub) and fleet route management (Transport Hub).
5. **Academics Matrix**: Comprehensive grading ledgers and one-click official Word transcript generation.

## 🛡️ Sovereignty & Security
Architecture is built to be compliant with the **Tanzania Personal Data Protection Act (PDPA) 2022**, ensuring institutional data remains secure and under the school's sovereign control.
