# **App Name**: ShuleDirect Pro

## Core Features:

- NECTA-Compliant Academic Module: Automatically calculates and aggregates O-Level and A-Level grades, class rankings, and division classifications according to NECTA's complex tiered rules, functioning as an intelligent tool to eliminate manual errors and generate consolidated reports.
- Advanced Fee Management System: Enables definition of complex, multi-tiered fee structures based on academic level and services, generates automated invoices, supports customized installment plans, and tracks all financial transactions in real-time.
- Mobile Money Payment Integration: Seamlessly processes school fee payments directly through popular Tanzanian mobile money platforms (e.g., M-Pesa, Tigo Pesa) via an aggregator like ClickPesa, with automated reconciliation based on control numbers and webhooks.
- Dynamic SMS Communication Platform: Sends automated notifications and urgent alerts for fee reminders, attendance, and critical announcements using local bulk SMS aggregators (e.g., Beem Africa, NextSMS) for high delivery rates in Tanzania.
- Offline-First Data Synchronization: Allows administrative and teaching staff to operate continuously without internet by locally storing data (SQLite, IndexedDB) and intelligently performing delta synchronization of changes once network connectivity is re-established.
- Granular User Roles & Permissions: Provides distinct access levels and functionalities for school owners, headmasters, teachers, bursars, and parents, ensuring data security and relevant control over system modules.
- NECTA Data Export Tool: Generates pre-formatted, NECTA-compliant CSV or XML data files from internal records for easy submission to the national PReM and PReMS portals, significantly reducing double data entry.

## Style Guidelines:

- Primary color: A strong, professional blue (#1F5BA6) for reliability and an educational feel, reflecting institutional trust and digital transformation.
- Background color: A very light, subtle blue-grey (#ECF0F6) to provide a clean, academic, and calm backdrop for various data displays and forms, fitting a light scheme.
- Accent color: A vibrant violet-blue (#945CE6) used sparingly for interactive elements, calls to action, and highlights, offering a sophisticated contrast while maintaining harmony.
- Headline font: 'Space Grotesk' (sans-serif) to convey a modern, tech-forward, and authoritative presence for titles and prominent text.
- Body font: 'Inter' (sans-serif) for high legibility and a neutral, objective aesthetic, ideal for detailed reports, administrative content, and general body text.
- Use a professional, line-based icon set with clear visual metaphors related to educational, financial, and administrative tasks, ensuring immediate recognition across the system.
- Implement a responsive, modular dashboard-centric layout with a clear hierarchical navigation. Emphasize data-dense components that are scannable and easy to digest, suitable for various device sizes.
- Utilize subtle, non-intrusive animations for state changes, data loading, and transitions between sections, enhancing perceived performance and user experience without causing distraction.
